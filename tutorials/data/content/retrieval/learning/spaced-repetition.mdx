# 间隔重复

我把新概念安排在当天、第二天、第四天和第八天回看，而不是连续几个小时重复阅读。每次只写一个可回答的问题，并在答案中保留一个例子；如果连续两次答错，就把间隔缩短并换一种解释。卡片数量控制在每天二十张以内，才能长期坚持。

每周日看一次统计，记录完成率、正确率和仍然混淆的主题。学习计划不追求每天完美，而是让节奏可持续、结果可衡量。统计笔记里的均值、分布和抽样例子也用同样方法复习，避免只背术语而不会判断证据。
