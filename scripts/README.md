# 仓库脚本

`scripts/` 只保存仓库维护和发布检查脚本，不是运行时库，也不是业务代码。

| 脚本                         | 用途                                                     | 对应命令                    |
| ---------------------------- | -------------------------------------------------------- | --------------------------- |
| `verify-docs.mjs`            | 检查维护范围内 Markdown/MDX 的本地链接、排除项和目录目标 | `corepack pnpm verify:docs` |
| `verify-packed-consumer.mjs` | 构建后检查打包产物的 ESM、CommonJS、类型和原生消费者路径 | `corepack pnpm verify:pack` |

文档检查会排除 `eval/`、编译产物、依赖、原生构建目录和测试夹具；维护范围由脚本
中的 `maintainedDocumentRoots` 明确列出。新增重要文档范围时，先更新范围入口，再
同步维护这个清单和测试结果。

脚本的行为以源码和 `package.json` 的调用方式为准。修改脚本后，至少运行对应的
验证命令，并按 [测试与验证](../docs/TESTING.md) 报告未执行的环境相关检查。
