# 车票预订

预订长途车票时先核对出发日期、车站城市和抵达时间，再比较直达与中转。高原旅行不安排到站后立刻参加高强度活动，尽量留出半天适应；如果需要换乘，至少预留一小时并确认是否要重新进站。

付款前把乘车人证件、行李数量和退改规则再看一遍，保存订单号但不把证件信息放进普通旅行笔记。纸质或离线截图留一份，以防网络不稳。订票完成后再按行程整理衣物、药品和水，避免临出门才发现背包太重。
