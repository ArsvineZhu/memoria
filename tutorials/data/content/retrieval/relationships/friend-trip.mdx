# 朋友出行

和朋友周末出行时先约定预算、集合地点和“必须做”的一件事，其余留给现场决定。上次我们上午逛市场，下午找咖啡店聊天，晚上在住处附近吃饭，没有为了拍完所有景点而赶路。同行的人如果想休息，可以在同一个区域自由安排，不要求每一步都同步。

出发前共享一页简短行程和紧急联系人，车票与住宿由各自确认，公共费用用记账应用平分。回程后把好吃的店和下次想去的地方写进清单，不马上安排下一次旅行。这样的慢节奏既保留朋友相处时间，也不会打乱睡眠和恢复。
