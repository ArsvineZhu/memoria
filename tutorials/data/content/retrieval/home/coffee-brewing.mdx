# 手冲咖啡

目前常用浅烘焙豆，粉水比 1:15，水温约 93 摄氏度，先闷蒸三十秒再分两次注水。总时间超过三分钟时，下一杯先把研磨调粗一点；味道太薄则检查水温和注水速度。每次只改一个参数，并把豆子、日期和结果记下来。

咖啡准备放在早晨专注工作之前，磨豆、烧水和清洗器具组成一个可重复的开始信号。下午尽量不再补第二杯，以免影响睡前固定步骤。周末做饭或摄影时也会使用同一套秤和计时器，让日常记录服务于创作而不是增加负担。
