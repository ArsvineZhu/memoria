# 远程办公

书桌只放显示器、键盘和当天的纸质清单，工作设备与休息区尽量分开。上午用九十分钟时间盒处理深度任务，下午把会议集中在两个时段；重要决定写进文档而不是只留在聊天记录里。这样可以减少来回切换，也方便同事异步跟进。

下班前做十分钟收尾：关闭开发环境，写下明天的第一步，手机切换到个人模式，然后离开书桌。即使还有未完成的工作，也先把它放入待办。压力明显升高时，我会配合散步和拉伸恢复，而不是在晚上继续打开工作通知。
