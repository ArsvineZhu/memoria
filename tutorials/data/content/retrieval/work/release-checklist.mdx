# 发布清单

发布前先确认迁移脚本可以重复执行，生产备份已经完成，并在预发布环境跑过完整升级和回滚。每个数据库变更都要写出旧版本兼容窗口，避免应用先上线而旧字段已经被删除。检查结果与负责人放在同一张清单里，不靠口头确认。

上线后的前十五分钟重点看错误率、p95 延迟、队列长度和数据库连接数。若任一指标超过预设阈值，先暂停继续扩容，再按照回滚步骤恢复上一版。事故跟进记录要链接本次发布编号，这样以后复盘时能快速查到迁移、监控和回滚证据。
