# 网络排查

家里网络偶尔断线时先记录发生时间、影响的设备和路由器指示灯状态，再分别测试有线、无线和外部站点。上次问题集中在晚上，重启后暂时恢复；后来把路由器固件更新、散热位置调整，并把工作电脑改接有线，视频会议稳定了很多。

排查顺序固定为检查电源和网线、查看设备日志、确认运营商状态，最后才恢复出厂设置。保存配置备份和服务商电话，不在问题发生时临时搜索。远程办公需要网络稳定，但如果只是单台设备异常，就先排除电脑和网卡，不把所有问题都归咎于路由器。
