# 邻里互助

邻居需要短期照看植物或代收包裹时，先确认时间范围、联系方式和钥匙交接方式。物品借用写清名称、状态和归还日期，重要物品不在楼道或公共群里公开细节。帮助别人之前先确认自己有时间，不因为不好意思拒绝而打乱工作和休息。

上次出差时邻居帮忙收了快递，我回家后带了一袋咖啡豆表示感谢；对方更需要的是提前说清取件时间。互助结束就把提醒关闭，避免过期通知反复打扰。家庭聚会或公寓维修需要公共协调时，也沿用这种简短、明确、有边界的沟通方式。
