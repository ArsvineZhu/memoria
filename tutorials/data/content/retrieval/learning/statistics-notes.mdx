# 统计笔记

读一张图表时先问样本来自哪里、指标如何定义、缺失值怎样处理，再看结论是否显著。平均数容易被极端值拉动，所以会同时看中位数和分位数；相关关系也不能直接说明因果。把这些问题写成检查清单，比背一串术语更能帮助实际分析。

学习安排采用每周三个短时段：一次读概念，一次手算小例子，一次解释结果。每次留下可复现的数据和假设，月底用完成率与错误类型衡量进步。若某个概念总是答错，就回到间隔重复卡片，而不是盲目增加当天的学习时长。
