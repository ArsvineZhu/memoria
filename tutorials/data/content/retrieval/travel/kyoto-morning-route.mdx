# 京都早晨

想避开游客高峰时，早上七点左右从住宿地出发，先走安静的小巷，再到一处寺院外苑，最后沿河边步行。热门景点只选一个，不在中午前后反复换乘；早餐准备成饭团和热茶，到了人多的区域就能随时离开。

路线记录要写清入口、洗手间和可以休息的咖啡店，而不是只保存地图截图。下雨时把河边段换成室内展馆，鞋子和轻便雨具放在随身包最外层。旅行的重点是保留观察时间，像摄影练习一样记录光线和街道变化。
