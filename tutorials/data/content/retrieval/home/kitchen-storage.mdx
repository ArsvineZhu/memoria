# 厨房收纳

厨房按使用频率分三层：每天用的锅具和咖啡器具放在腰部高度，每周用的烘焙用品放在上层，备用食材按保质期从前到后排列。透明盒标注开封日期，刀具和清洁用品分开。收纳目标是让周末做饭前十分钟就能找到全部材料。

每周五检查冰箱，先用快过期的蔬菜规划一道菜，再决定采购清单。一次只准备两到三份，避免为了节省时间留下太多剩菜。清理时顺便擦拭水槽和咖啡区域，记录缺少的容器；这些小任务和预算、早餐计划互相影响。
