# 首屏性能

最近的页面实验把首屏脚本拆成关键路径和延后加载两部分。先删除没有使用的依赖，再用动态 import 推迟设置页和图表模块；主 bundle 减少约 18%，在移动网络上首次可交互时间也更稳定。图片统一使用合适尺寸，避免 CSS 缩放大图。

下一步要同时看 LCP、INP 和实际用户的网络分布，不只看本地开发机的 Lighthouse 分数。组件初始化前先判断是否真的进入视口，列表数据采用分页。这个结论会和 SQL 索引笔记一起复查：前端变快不代表后端查询就合理。
