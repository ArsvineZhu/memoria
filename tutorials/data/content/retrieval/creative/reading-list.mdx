# 阅读清单

当前只保留三本正在读的书：一本长篇小说、一本统计入门和一本摄影随笔。每次阅读前写下想回答的一个问题，读完记录三条事实和一个疑问；如果一本书连续两周没有翻开，就移到待阅读，不让“正在读”变成收藏夹。

好段落会记下页码、主题和我为什么喜欢，避免只复制文字。周日回看读书记录，把能帮助写作或摄影的观察链接到对应项目。中文阅读笔记使用同一流程，术语和复杂概念则安排在间隔重复中，保证阅读真的转化成理解。
