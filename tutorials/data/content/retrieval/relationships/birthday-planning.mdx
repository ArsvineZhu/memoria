# 生日计划

生日提醒提前六周触发，先确认对方那一周是否方便，再决定单独吃饭、家庭聚会或寄一份礼物。两周前完成预算和预订，一周前确认地址、过敏信息和交通。提醒内容只保留必要信息，礼物偏好放在私密清单里。

如果多人一起参加，就把集合时间、付款方式和取消规则写清楚；不方便到场的人可以录一段祝福或之后单独见面。活动当天不安排过多项目，留出聊天和临时变化的空间。结束后记下对方真正喜欢的部分，为下一次准备提供参考，而不是建立昂贵的固定模板。
