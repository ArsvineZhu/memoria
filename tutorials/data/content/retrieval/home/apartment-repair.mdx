# 公寓维修

报修前先拍照并写下首次发现时间、影响范围和临时处理方式。水槽渗水时我先关掉角阀、清空柜内物品，再把照片、房间位置和可上门时段发给物业；没有自行拆开可能属于公共管线的部分。沟通记录按日期保存，方便确认责任和进度。

小问题可以每月集中检查一次：门锁、灯具、窗户密封和烟雾报警器都列在清单上。维修完成后测试两次并记录更换零件，不把“看起来好了”当成验收。遇到需要专业电工或水工的情况，优先按物业和当地规定处理，安全比省一次上门费重要。
