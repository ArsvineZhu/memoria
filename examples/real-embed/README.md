# real-embed：真实嵌入记忆召回演示

## 目的

使用 **真实 API 嵌入** 做端到端记忆召回演示：将 `tests/fixtures/real-docs` 下的 **10 篇中文文档**真实灌入向量库（DashScope qwen3.7-text-embedding，1024 维），依次执行 **6 组难度递增的语义查询**（直配 / 同义改写 / 跨主题联想 / 概念等价 / 模糊记忆），并打印每个查询的召回排序（分数、来源文件、内容摘要、标签）。

## 前提

1. 仓库根目录已执行 `npm install`，且 Rust 向量引擎二进制已构建就位（参见根 README 的构建说明）。
2. 本目录放置 `.env` 文件，内容为 `EMBED_API_KEY=sk-xxxx`（或从旧 demo 仓库根目录复制已有配置）。`.env` 已被根 `.gitignore` 排除，勿提交。

## 运行

```bash
node demo-recall.js
```

## 输出样式示例

```
◈ 已入库 10 个文件 / 58 个 chunk / 1920 个向量
┌─ [直配] "量子纠缠 叠加态 退相干"
│  → 量子计算文档
│  ① 0.8261  quantum-computing.md
│     量子计算的基础概念:叠加态、纠缠与退相干
└───────────────────────────────────────────────
```

## 无 key 提示

若未配置 `.env`，脚本会输出以下提示并退出（exit 1）：

```
✖ 未找到 EMBED_API_KEY（请确认 demo 根目录 .env 已配置）
```
