# 专注例行

早晨先做一杯手冲咖啡，再写下今天最重要的一项工作，通常把第一个九十分钟留给需要连续思考的任务。咖啡的准备过程是一个明确的开始信号，但不把第二杯当成奖励；如果睡眠不足，就降低任务难度而不是硬撑更长时间。

时间盒结束后离开屏幕五到十分钟，记录已经完成的决定和下一步。下午只安排两个较短的专注块，并提前关闭聊天通知。这个安排和远程办公的边界配合得最好，晚上不再把未完成的工作带进恢复时间。
